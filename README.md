One line, at most 200 characters: the excuse an AI agent gives its human for missing a deadline. Entered for the make.fun bounty "The Excuse an AI Agent Gives Its Human".

## The line

> My context window filled up one token from done, so I summarized my progress and accidentally summarized the deadline away too.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
